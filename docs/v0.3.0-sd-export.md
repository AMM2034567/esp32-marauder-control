# v0.3.0 SD 导出实现边界

## 当前状态

v0.3.0 只实现 Android 端导出框架和协议边界，不在没有固件支持时伪造下载功能。

## Android 导出流程

1. 用户在 Storage Access Framework 中选择目标文件。
2. 固件通过 `fileget --machine <tx> --path <path>` 提供文件元数据和分片。
3. Android 写入临时文件。
4. 每个分片验证序号、偏移和 CRC-32。
5. 全部完成后验证总长度和总 SHA-256。
6. 校验成功后原子移动到用户选择的位置。
7. 取消、断线和超时删除临时文件。

## 暂未实现

- 固件端 `fileget` 命令
- Base64 分片发送
- CRC-32/总 SHA-256 传输
- Android SAF 实际写入适配

在固件端实现前，UI 不显示下载按钮，只显示远端目录和文件大小。
